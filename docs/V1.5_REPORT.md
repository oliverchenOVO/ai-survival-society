# AI Survival Society v1.5.0 — Living World

## 1. Goal
沿用 v1.4 架構，使十二個自主角色能使用、爭奪與改變世界。沒有固定角色劇本、傳送相遇、強制攻城或為畫面呼叫 gameplay RNG。

## 2. Architecture
`core/living-world.mjs` 管理八個 POI、有限物件、世界知識、控制、天候與危險。Simulation 固定 tick 更新世界；既有 Utility candidate/executor 執行互動。UI 只讀權威或 Replay snapshot。新 object ID 是世界局內序號；Story ID 仍由 crypto 產生。

## 3. Interactable system
統一 id/type/position/state/capacity/durability/owner/controller/cooldown/usable/visible/metadata；`canInteract` 驗證類型、能力、range、容量、電力、charge 與 cooldown，`getUtility` 評分，`performInteraction` 唯一執行狀態變化並記錄事件。Door 有 closed/open/locked/broken；open locked 需耗能與破壞耐久。補給箱有限且可搜空。Bed 有佔用與恢復效果。Campfire 消耗木材、有限燃料，增加休息效率與夜間視野，storm 快速熄火。醫療站消耗 medicine 或有限 charges；generator 三秒累積修理恢復本地 village power zone。Watchtower 擴大視野、減少部分傷害但可被殺。Radio 有 cooldown，廣播事件與收聽者記憶。

## 4. POI system
Village、Clinic、Watchtower、Ruins、Depot、Shelter、Bridge、Lake 各自有 risk/shelter、有限資源、互動物件、佔用、控制與 recentEvents。重要藥品、武器、水與木材集中於設施或補給箱；原散落資源仍保留，維持探索與互補交易。

## 5. Utility integration
候選分數結合 HP、energy、hunger、personality、距離、danger、past conflict、known controller 關係、天候與夜晚。角色只能根據觀測過的物件與可能過期的存量評估；到達後重新驗證權威狀態。Station 不能無限醫療；空箱產生 DISAPPOINTED_SEARCH。空間控制調整風險而非禁止進入；原 talk/trade/cooperate/ally/attack 繼續競爭效用。

## 6. Territory memory
World knowledge 每個 POI 保存 seenAt、controller、controllers、物件 snapshot、危險與 lastConflict。角色另保存造訪次數與控制秒數；事件記憶附 poi/position，仍限 40 筆。Inspector 可展開世界認知。據點停留十秒且無高敵意競爭可控制；聯盟持有人可共同維持，離開八秒／死亡且無同盟維持後可釋出、被別人接管，競爭進入會記錄 POI_CONTESTED。

## 7. Weather
90 秒交替 day/night；Clear/Rain/Storm 使用同一權威狀態。夜晚降低視野及移動信心，提高火與庇護效用。Rain 小幅減速、Storm 更強減速／視野降低；Director Storm 直接更新此系統，沒有第二套天候 executor。Three.js 天空、光線、雨與標記讀此狀態。

## 8. Hazards
Seed 決定有限 fire/flood。Fire 有 radius、until、damage 與 spreadChance metadata；本版不實作野火擴散（stretch）。Flood 使北橋局部 crossing 成為 blocker。危險造成傷害、逃離候選與 navigation risk；開始／結束均進 EventBus。不是流體模擬或真實火焰傳播。

## 9. Perception
Distance、簡單 rectangle blockers、closed doors、night、storm、campfire、watchtower 與 hide/cover 影響感知。World knowledge 分 unknown/recently_seen（8 秒內）/known（35 秒內）/stale。已知庫存不代表即時庫存；LLM 也不再得到全部角色或全島資源。沒有向量資料庫、3D ray-tracing vision。

## 10. Navigation
在原 movement 上加小型 visibility graph，繞過 expanded wall/door/hazard rectangles；兩個聚落／遺跡入口與北橋造成空間選擇。到 waypoint 不等於到原目標，避免隔牆拾取資源。ROUTE_CHANGED 與 hazardAvoidance 分開計數；非危險牆體繞路不能冒充 hazard avoidance。Hide/cover 以可見度與傷害優勢交換移動及採集機會。

## 11. Persistence
Root schemaVersion 1 保持既有格式，加 `world.schemaVersion:1` 與 checkpoint RNG/resource timers；`Simulation.fromSave` 恢復 agents、knowledge、world、events、timeline、timers、RNG。`/api/load` 僅允許未完成 v1.5 checkpoints，先存目前世界，重設 LLM queue，以 paused 開啟。舊檔仍能 Story/Replay，不能續跑未記錄的世界。Prune 使用索引 metadata，不再於每次存檔全文讀所有永久故事。Atomic rename、刪除 tombstone、privacy whitelist 保留。退出時先保存世界，再終止 WebSocket 與未完成 HTTP 連線；新增 partial-header socket 測試，防止桌面退出卡在 header timeout。

## 12. Replay
每五秒取樣完整物件、控制、天候、hazard 與 depletion。Replay 使用最近不晚於時間游標的 sample，不使用最終世界。舊樣本沒有 world 時安全降級成原景觀。這不是每 frame 的物理重建；世界跳變最多有五秒取樣誤差。

## 13. Story integration
World Moments 單獨顯示，Major Moments 加入 world weights，social/ending 仍有更高權重。Life Story Important Places 由 visits/controlSeconds/final position 生成，不捏造動機。Public exports 明確 whitelist world/POI/object/事件欄位，不輸出 checkpoint、provider credentials 或內部路徑。Markdown 包含世界事件及重要地點；既有 PNG 分享、關係歷史、MVP、深連結與永久典藏保留。

## 14. Determinism
World construction 使用 seed 衍生的獨立 stream；runtime gameplay 使用 Simulation seeded RNG。相同 v1.5 seed 及 Director timing 可重現整局。視覺的時間、procedural pulse、Story ID、語言選擇不呼叫 simulation RNG。v1.5 明確改變 gameplay，不宣稱 v1.4 benchmark unchanged。Checkpoint 中途保存／載入後續跑用 deepEqual 驗證。

## 15. Benchmark
`scripts/benchmark-world.mjs`：primary 1–50，holdout 1001–1050，utility-only/no Director。記錄結局、duration、trade/alliance/betrayal/combat、socialEvents、POI visits/interactions/search/rest/heal/repair/control/shelter/hazard avoidance/broadcast/fire/doors。Primary 平均每局 51.24 次造訪、23.04 次世界互動、6.72 次控制取得、110.46 次社交事件；holdout 為 45.46／24.96／7.24／110.42。Primary 全滅率 0%，holdout 2%；所有 100 局都有世界與社交互動。修理平均 0.84／0.78、廣播 0.42／0.28、營火 0.26／0.42，未強迫每局每種事件發生。Golden SHA-256 覆蓋完整 events/agents/world/ending。基準檔 `docs/qa/world-v1.5-golden.json`；重新跑只驗證，不默默重寫。修改 gameplay 時需明確 `--update` 並檢查兩組 cohort，不能以固定劇情補事件。

## 16. Performance
同機 1000 ticks 測量（Seed 7、250 秒）：v1.4 wall mean 0.0605 ms/p95 0.1977 ms；v1.5 wall mean 0.3603 ms/p95 1.3403 ms。計算量增加，但 10× 為每秒 40 ticks，仍低於每 tick 25 ms 的 wall budget。Snapshot 約 124 KB→235 KB；world samples 增加 archive 體積。12 Agents × bounded POIs/objects，無額外每 frame gameplay 搜尋；Three.js registry reuse mesh，僅 UI 的小型場景集合更新。八個據點標記做有限的螢幕空間避讓；控制者顯示前兩名及其餘人數，完整名單保留在 tooltip，標記移位後有定位細線。詳見 world-performance-v1.5.json；最終 Browser 於 1920×1080 取樣 requestAnimationFrame：1× 60.15 FPS、10× 65.13 FPS；Electron 為 75.79／72.80 FPS。每次取樣約兩秒，先前同時封裝／其他開發負載下曾測得 40–52 FPS，這不是所有顯卡的效能保證。完整資料見 world-browser-v1.5.json／world-desktop-v1.5.json。

## 18. Known limitations
視線／hazards 用平面近似，非完整 terrain ray casting；建築仍是原有 art 加功能物件，沒有室內 navmesh。River flood 僅封鎖北橋局部；可繞行，不模擬全島水位。控制沒有 RTS 捕獲、法律、硬性禁入；被動停留也可建立控制。Broadcast 是範圍訊息與位置記憶，不保證真實，無強制翻譯 LLM 自由文字。Fire spread、barricades、trap、野生動物、破壞／修橋與影片列為未做 stretch。World Moments 最多 12 則；完整 timeline 仍可過濾所有世界事件。Public Story 不含私有 RNG checkpoint，需原本本機存檔才能續跑。持久保存的故事會累積磁碟容量，可在檔案庫明確刪除。
