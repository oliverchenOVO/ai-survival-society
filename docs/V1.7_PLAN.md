# v1.7 Spatial Intelligence & Physical Interaction

1. Current movement: actions.moveAgent requests living-world navigationWaypoint and moves directly in XZ. The existing visibility graph is rebuilt on every blocked movement call. Arrival is a 1.2–1.7m range check.
2. Collision limitations: four wall segments and doors affect visibility/path choice but movement has no swept final collision check. Agents, furniture, water and decorative structure do not constrain motion.
3. Navigation limitations: no cached path, queue/portal ownership, vertical route, interaction approach or stuck recovery. Watchtower height is a renderer projection.
4. Collision representation: versioned simplified rectangles/circles, height zones and named Blender markers, exported as JSON. Same source feeds authoritative tests and render alignment overlay. Small debris remains decorative.
5. Navigation: deterministic A* on a bounded 2.5D grid within polygon regions, explicit portals/vertical route nodes, cached paths and segment smoothing. Closed doors/hazards invalidate affected routes; renderer never computes authoritative paths.
6. Local avoidance: swept character circles, stable-ID priority, deterministic lateral candidates, collision-safe yielding and bounded stuck recovery. No gameplay teleport.
7. Interaction slots: explicit approach/facing nodes, limited reservation and occupied states, expiry/death/target-change release, deterministic queue and utility wait penalty.
8. Determinism: gameplay intentionally changes; preserve historical golden and establish separate 50 primary + 50 holdout v1.7 facts/hash golden. Timing measurements excluded from deterministic facts.
9. Save/replay: spatial checkpoint stores paths, slot/portal reservations and metrics. Revalidate restored paths/reservations. Legacy unfinished saves explicitly record nearest-legal-point migration; completed Stories/replays retain their historical coordinates. Replay consumes sampled world/positions, without rerunning pathfinding.
10. Benchmark: collision/LOS/navigation/avoidance/queue/high-density fixtures, permanent-stuck and overlap gates, path efficiency/replans/waits/failures and separately measured A* nodes/p95 time/avoidance cost. Rerun all established QA including actual Windows portable, both desktop sizes and mobile Story.
