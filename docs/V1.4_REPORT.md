# AI Survival Society v1.4.0 — Shareable Simulation Stories

## 1. Goal

將完成局保存為可獨立閱讀、重新觀看、匯出及分享的故事。沿用既有專案、12 名角色與雙語觀測站；沒有新增 gameplay 或改寫模擬核心。

## 2. Architecture

`server/persistence.mjs` 升級原有 saves/logs 典藏，沒有第二套 Story 資料庫。
`src/story/facts.mjs` 是純資料整理與顯示函式，不讀取 active world、不匯入 core RNG。
Node authoritative API 讀取已保存完成局。React Story 頁 lazy-load；目前模擬可在背景繼續運行。

## 3. Story schema

原始 replay `schemaVersion: 1` 保持相容，增加 `simulation_id`、`startedAt` 與 `story`。
`story.storySchemaVersion: 1` 含 simulationVersion、ID、日期、duration、outcome、角色生存／命運／主要人格／關係指標／事件參照、majorMoments、finalThree、awards、summary、relationshipChanges。
完整 events、agents、relationships、positions、stats、history、timeline 沿用原始保存欄位，整理後的資料只保存參照與計算結果，不重複原始陣列。完成時凍結事實，LLM Historian 後續完成只更新 narration。

## 4. Story ID

格式 `S-` 加 16 個 Crockford Base32 字元，80-bit `crypto.randomBytes`，不包含路徑或角色名，不使用 simulation RNG。生日碰撞機率在一百萬局時約 4×10⁻¹³。
舊 `timestamp-seed` ID 以 SHA-256 前 80 bits 作穩定轉換並原地 atomic migration；原 matchId 可作 replay alias。Story、Replay、JSON、Markdown 和 PNG 採同一 canonical ID。

## 5. API

| API | 行為 |
|---|---|
| GET `/api/stories` | 同一典藏的清單，包含完成、未完成及可診斷的損壞紀錄 |
| GET `/api/stories/:id` | 完成局公開白名單資料與分享連結 |
| GET/POST `/api/stories/:id/export?format=markdown&lang=en` | Markdown；預設 zh-TW；未指定 format 則安全 JSON |
| DELETE `/api/stories/:id` | 原子更新 tombstone，刪除 save/log；阻止晚到的 Historian 或 autosave 復活資料 |
| GET `/api/replays/:id` | 沿用 replay；完成局套用安全白名單 |
| GET `/story/:id` / `/replay/:id?t=` | 直接開啟 SPA，支援重新整理 |

未知 ID 404、已刪除 canonical ID 410、無法讀取／未完成的 Story 422；UI 顯示雙語合理錯誤。ID 只接受嚴格模式，拒絕任意路徑。POST 與 DELETE 同源保護一致。

## 6. Story Page

Hero → 五段故事 → 關鍵時刻 → 最後三個心智／最後殞落者 → Cast／資料稱號 → 社會歷史 → 收合時間軸 → Historian → 分享／匯出。
Hero 不依賴 LLM；日期、Seed、結果、存活時間與五種統計来自完成局。沿用 RobotPortrait 與深色、薄線、低飽和事件色彩。
時間軸分類／事件／角色／起訖秒數過濾，每頁最多 25 筆。角色 modal 與 pair timeline 同樣限制大量 DOM。

## 7. Major Moment ranking

基礎分：終局 150、背叛 100、死亡 85、結盟 55、瓦解 60、攻擊 18、交易 25、互助 35；Director 45–65。
首次事件 +25（首次結盟 +55）、記錄關係變化絕對值總和 ×20、最後三次死亡 +35、最後階段攻擊 +20、relic +20。
按分數選出最多 12 筆，限制普通重複類型最多 3 筆，死亡／背叛／終局例外，再按時間排序。少事件的短局不捏造事件補足數量。排序使用 Map，10,000 事件的單元測試在兩秒門檻內。

## 8. Agent Life Story

每名角色有八種人格、生存時間、結局、四種計數、重要事件與記憶、最早社交和最近重大衝突的 template biography。內容逐字引用已記錄事件，沒有推測動機或捏造心理轉變。
Closest recorded ally 取曾結盟者的最終雙向 trust 合計最大正值；Greatest rival 取双向 hostility 合計最大正值；Most trusted／feared 取此角色 outgoing trust／fear 最大正值。同值全部顯示，無正值顯示沒有可用證據。
Final Three 以生存時間降序，winner 優先；同刻死亡以 ID 作穩定顯示次序，明列其他同時殞落者，包含三名之外的同刻死亡角色。這並非聲稱同 tick 存在先後勝負。

## 9. Share Card

本機 SVG → Canvas → 1200×630 PNG。包含品牌、winner／extinction、Seed、duration、kills、alliances、ID 与進入／生還數。使用可靠 CJK font stack，不嵌入大型字體、不呼叫 SaaS。
Browser 以 Blob download；Electron 的安全下載白名單增加 `.png`、`.md`，保持 sandbox、contextIsolation 與無 Node renderer access。QA 檢查實際 PNG IHDR 尺寸和原生下載完成狀態。

## 10. Export

安全 JSON 仍為可匯入的 schemaVersion 1 replay，保留回放所需 fields 與統計；provider 設定不在完成局公開 export 中。
Markdown 包含 title、Seed／duration、結果、五段摘要、統計、重要時刻、所有角色 biography 與 Historian。Markdown 文字與 HTML／SVG 特殊字元分別轉義。HTML／PDF export 不列為本版 P0。

## 11. Replay integration

Story moments 使用 `/replay/:id?t=timestamp`。App 的最小新增 props 載入既有 replay、限制 seek 在有效區間，保留原播放引擎。Replay bar 增加返回 Story。完成 modal 可立即觀看自動保存的故事，不需手動 Save。
連續模式與新局不影響舊 Story 或凍結的結算 export，原有 results regression 已通過。

## 12. Localization

所有新字串在 `src/i18n/story.mjs` 合併進既有 catalog；zh-TW／en 具有一致 keys 與參數。模板結果即時翻譯；自由 LLM prose 保留原文，公開輸出僅移除已知 credential／本機路徑模式。
沿用 Microsoft JhengHei 等 font fallback。現有 localization QA 的 whitelist 只新增 ID、Markdown 及格式化 Story ID，沒有放寬一般英文漏翻檢查。

## 13. Compatibility

舊 schemaVersion 1 saves 原地升級、不重建 replay。旧档缺完成日期與版本時分別顯示日期未知與 legacy，不推測真實 wall-clock 結束時間。
已完成故事不再受 maxStoredMatches prune；未完成檔與 debug logs 仍受上限管理。磁碟用量會隨完成局增加，Delete、備份與 DATA_DIR 由使用者管理。
未讀懂的版本／損壞檔保留診斷與刪除能力，沒有靜默丟棄。先前版本已 prune 的資料無法恢復。

## 15. Security

Story／completed replay／completed JSON 使用公開白名單，排除 LLM config、credentials、runtime fields、API keys 與機器路徑。文字再移除常見 API/GitHub token、Windows／home path 和帶 credential/query 的 URL。
React 只渲染文字，無 `dangerouslySetInnerHTML`。LLM HTML injection 實測只顯示文字。SVG/XML metadata 使用 escapeXML，Markdown 特殊字元轉義。
Privacy redaction 是常見模式防護，不能辨識自由敘事中的所有自然語言個資；公開前仍應依實際模型資料來源控管。既有本機 active-state/config 控制 API 不是本版新增的公共帳號／權限系統。

## 16. Deployment implications

`DATA_DIR` 對應唯一典藏；Docker runtime 複製 `src/story`，既有 `/data` volume 保存 saves、logs、preferences 與 deletion tombstones。搬移資料時一併保留 `saves/.deleted.json`。
`PUBLIC_BASE_URL` 接受無 credentials/query/hash 的 HTTP(S) URL。它只組分享連結，不上傳、不複製本機故事。公開 server 必須擁有同一典藏；base path 需由 reverse proxy 正確轉送。
**Implemented:** Story route 的 server-rendered title、description、og:title、og:description、og:url、twitter summary metadata，crawler 無需執行 JS 即可读取文字。
**Prepared for server-side image metadata:** PNG 目前為 client download，尚無 crawler 公開 PNG route／og:image；不宣稱已完成社群圖片 preview。
本版不實際公開部署；對外部署仍需控制 API access、TLS、存取政策與備份。Private GitHub Release 也不等於公共 Story hosting。

## 17. Known limitations

未提供完整 directional relationship evolution：事件只記錄部分影響，含未記錄的 clamp、asymmetry 與 Director 改變，因此僅呈現最終 directional values 與已知 event influences／pair interactions。
Replay 沿用每五秒觀測取樣、非重新執行 core；原有限制不變。LLM prose 不強制翻譯。影片、QR、public gallery、比較、animated timeline、HTML/PDF export 留待後續版本。
每個完成局永久保存需要磁碟容量與備份；没有自動雲端同步。本機網址不可直接分享給另一部電腦。Unsigned portable 在部分 Windows 系統仍可能觸發平台提示。
