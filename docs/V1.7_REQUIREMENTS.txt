你現在要在既有 AI Survival Society 專案上開發下一個正式版本：

# AI Survival Society v1.7
## Spatial Intelligence & Physical Interaction

這不是新專案。

請在目前既有 private GitHub repository、v1.6.0 程式碼、Living World、Physical World、Story、Replay、i18n、Browser、Electron 與 deterministic benchmark 架構上繼續迭代。

---

# 本版本核心目標

讓 Agent 不只是「知道目標在哪裡」，

而是真的必須：

- 找到可走的路
- 穿過門
- 繞過牆
- 繞過家具
- 避免其他 Agent
- 排隊進入狹窄空間
- 站在正確互動位置
- 使用有限容量的互動槽位
- 不能穿牆
- 不能穿人
- 不能隔牆拿東西
- 不能站在同一個座標疊成一團

本版本核心一句話：

> **The world must physically constrain behavior.**

# 嚴格限制

不要重寫整個 simulation。

不要把 Three.js renderer 變成 authoritative gameplay physics。

Authoritative simulation 必須仍然在 core/server。

Browser/Electron 只是 render / input / observer。

如果使用碰撞資料：

simulation 端也必須有對應簡化 collision representation。

不要只讓畫面碰撞、實際 AI 還穿牆。

# 核心功能 1 — Collision Geometry

建立：

Authoritative Collision Layer

不要直接拿完整 Render Mesh 當碰撞。

使用簡化：

- box
- capsule
- circle
- convex polygon
- rectangle
- portal
- height zone

每個 POI / 物件都可以有：

collisionShape

例如：

{
  "type": "box",
  "x": 12,
  "z": 8,
  "width": 4,
  "depth": 2
}

或：

{
  "type": "polygon",
  "points": [...]
}

Render Mesh 和 Collision Mesh 必須分離。

---

# 核心功能 2 — Blender Collision Export

擴充 Blender pipeline。

建立或更新：

`Art/Blender/generate_collision_data.py`

或合理命名。

每個重要 POI source 裡可以包含：

COLLIDER_
NAV_
PORTAL_
INTERACTION_

命名節點。

例如：

COLLIDER_Clinic_Wall_A
PORTAL_Clinic_Door_Main
NAV_Clinic_Floor
INTERACTION_MedStation_A

匯出：

JSON

例如：

`public/assets/world-collision.json`

不要要求 simulation 端解析 GLB mesh。

simulation 直接讀簡化 JSON。

# 核心功能 5 — Dynamic Door Collision

必須一致。

# 核心功能 9 — A* Pathfinding

建立穩定：

可以：

+

+

不要每 tick 重跑完整 path。

# 核心功能 10 — Path Smoothing

# 核心功能 11 — Dynamic Obstacles

以下可成為 dynamic obstacle：

- closed door
- flood blocker
- fire hazard
- wreck / body if appropriate
- occupied interaction zone
- temporary barricade if future exists

dynamic obstacle 改變時：

重新規劃。

避免：

# 核心功能 12 — Agent-to-Agent Local Avoidance

可實作：

核心要求：

Agent 不再互相穿過。

# 核心功能 15 — Queueing

例如：

- leave

不要硬 freeze 所有人。

# 核心功能 17 — Slot Reservation

Reservation 如果：

# 核心功能 28 — Stuck Detection

但仍有 path：

2. slight waypoint offset
3. replan
4. abandon action

禁止：

直接 teleport

除非 QA/debug special mode。
