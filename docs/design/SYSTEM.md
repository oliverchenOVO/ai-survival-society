# Visual system

Reference: concept.png, generated with the built-in Image Gen tool before client implementation. Prompt: complete AI Survival Society desktop observatory, dark navy shell, low-poly island, robot inspector, live feed, six Director actions and green/blue/red relationship network. World art uses true Blender GLB and procedural mesh geometry rather than a painted screenshot.

- Background #080f18; surface #101c28; text #e5edf0; muted #8499a7; borders #243540.
- Identity accent mint #88e5be; supply/warm light amber #e5b879; danger coral #ee827e; alliance blue #80bfea.
- Shell: 62px icon rail, 64px top bar, main viewport, 306px inspector, 220px lower feed/director/network band.
- Typography: system sans-serif, 13px body, 10px uppercase tracked labels, 21px identity headings, tabular numbers.
- Fine rectangular borders and 5px control radii; open rows, no nested card grid.
- Icons: Lucide, 18px, 1.6 stroke, consistent outlined style.
- Main controls: pause, restart, speed. Additional required workflows use matching compact controls: seed, auto-run, save/export, replay and model settings.
- Reference-generated example names, trait names and decorative tagline are superseded by the user's exact 12 names and required eight personality fields.
- Responsive: inspector becomes lower panel; bottom areas flow vertically below 1000px, full canvas remains usable. Reduce labels rather than overlap.
- Motion: orbit camera damping, interpolated robot movement with walking bob, supply beacon glow, event pulse/tracers, gentle sky and water.
