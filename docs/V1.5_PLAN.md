# v1.5 Living World plan

Existing v1.4 uses authoritative fixed-step Node simulation, seeded Utility choices, direct movement, EventBus, 5-second replay samples and schemaVersion 1 JSON archives. Three.js builds seeded decorative buildings independently. Agents know all resources in the ring; social perception is a constant radius. Director storm is a timed speed multiplier. Story freezes presentation facts and exposes a privacy whitelist. Save archives do not currently resume RNG state.

Implement a small authoritative `core/living-world.mjs` registry beside the existing world module. Eight POIs own a bounded set of typed objects. Contracts validate state, range, power, capacity, stock and cooldown before mutating anything. The existing executor moves to and executes these actions. Candidate evaluation uses observed object/POI snapshots, with stale information, relationships, survival needs, distance and hazards. No identity scripts, forced encounters or visual RNG in gameplay.

Doors and walls create two entrances; hazards add temporary navigation blockers. A small visibility graph finds a deterministic route around expanded rectangles/circles; no navmesh dependency. Weather and time modify perception, movement and resting. Control is a dwell-time claim with relational access cost and event history; absence/death releases claims. Fire and flood are seeded, finite world events. Director storm uses the same weather state; drops and treasure create finite caches.

Keep root schemaVersion 1 for archive compatibility, add `world.schemaVersion: 1` and a resume checkpoint with RNG state. Save/load restores exact authoritative state; old saves retain story/replay reading with no invented world history. Deep-copy world state into replay samples; renderer uses samples rather than final world. Story gains independent World Moments and data-derived places. Localized structured world event templates avoid translating model prose.

New deterministic golden reports: primary 1–50, holdout 1001–1050. Compare repeated event logs, agents, world, metrics and ending; preserve old benchmarks as historical records. Measure tick throughput, world/social emergence and actual browser/Electron at 1x/10x. Run all existing QA with updated gameplay assumptions, screenshots at requested sizes, portable packaging, private release only after acceptance.
