# 核心功能 1 — Interactable World Object System

建立統一：

World Interactable System

不要每個物件各自寫死。

每個 interactable 至少具有：

id
type
position
state
capacity
durability
owner / controller
cooldown
usable
visible
metadata

例如：

{
  "id": "med_station_01",
  "type": "medical_station",
  "position": {"x": 12, "z": -8},
  "state": "available",
  "durability": 100,
  "controller": "agent_04",
  "capacity": 2
}

支援統一 interaction contract：

canInteract(agent, object)

getUtility(agent, object, worldState)

performInteraction(agent, object)

emitEvents()

不要讓 Agent 直接任意改物件狀態。

所有行為經 simulation authority。

# 核心功能 4 — Occupation / Control

# 最重要的產品目標

完成 v1.5 後：

玩家不應該只看到：

「12 個 Agent 在一張 3D 地圖上移動。」

而應該看到：

「12 個 Agent 正在使用、爭奪、改變這個世界。」

例如一局可能自然出現：

Nova 和 Lyra 先佔領 Clinic。

暴風雨後，所有角色開始尋找 Shelter。

Atlas 修復 Village Generator，使診所重新運作。

Pax 發現北橋被洪水阻斷，被迫穿越 Ruins。

Rune 佔領 Watchtower，較早發現 Supply Drop。

Nova 離開 Clinic 後，Pax 趁機取得控制。

Lyra 試圖重新進入時爆發戰鬥。

最後 Story 裡可以看到：

不只誰背叛誰，

而是：

誰控制了哪裡，

哪些地方改變了局勢，

哪些環境事件迫使 Agent 改變策略。
