# AI Survival Society 1.0.0

A working 3D society of twelve autonomous robots, with Utility AI, evolving relationships and memories, six Director events, contracting safety zone, winner/historian, replay archive and optional local/compatible models.

Download AI-Survival-Society-1.0.0.exe and run on Windows x64. Node, Unity, Blender and Ollama are not required for the packaged app. Cold portable extraction takes about one minute; keep the window/process running while it opens. The executable is unsigned.

Verified: 10 behavioral/integration tests; 20 complete seeds; 15 grouped browser workflows at 1600x1000 and 390x844; actual unpacked and portable executable operations; real local model decision applied and historian generated; repeated launcher start/stop/restart.

Public hosting is not part of this release. Replay is observational sampled playback, and decorative objects do not block agent navigation. See FINAL_REPORT.md and README.md for precise limitations and source rebuild steps.
