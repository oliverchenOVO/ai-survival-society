# v1.4 — Shareable Simulation Stories

Existing saves already contain final agents, relationships, memories, positions, stats,
all events, historian and five-second replay samples. Reuse these arrays rather than
creating a second archive. The core and its RNG remain unchanged.

Missing: stable public identity, completion dates, derived narrative facts, ranked
moments, biographies, permanent completed-run retention, story routes and sharing.

Save schemaVersion 1 remains replay-compatible. Add simulation_id and a versioned
story facts block (storySchemaVersion 1). Facts reference existing event and agent
IDs. New IDs use independent cryptographic randomness; legacy IDs use a stable hash
of matchId. Migration writes the enriched save atomically in its original file.
Completed saves survive pruning until explicit deletion; unfinished saves and debug
logs remain bounded. Deletion tombstones prevent delayed historian writes restoring
a deleted run.

Node serves the unified library, whitelisted story views, exports and deletion.
Story routes read only persisted completed runs. /replay/:id?t= uses the existing
replay engine. /story/:id follows Hero → five-phase story → ranked moments → final
three → cast → social history → collapsed timeline → historian → sharing. Reuse
RobotPortrait, colors, fonts and localization. Paginate events; React escapes prose.

Derived claims use observed events and final metrics, with explicit ties and missing
data. Partial relationship deltas are labelled event influences, never reconstructed
as exact directional trust histories. Templates work without LLM; free prose remains
unaltered except public privacy redaction and safe rendering.

SVG-to-Canvas produces 1200×630 PNG locally. Markdown and safe JSON exports share
the story ID. PUBLIC_BASE_URL controls links, not uploading. DATA_DIR is the only
archive; Docker's /data volume preserves it. Server metadata will be explicit about
crawler image support; no claim that client-only rendering provides rich previews.

Validation: unit/API/migration/security tests, existing i18n/browser/desktop QA,
100-seed benchmark unchanged, simulation regression, dedicated Story Browser and
Electron flows, screenshots and private v1.4.0 release after acceptance.
