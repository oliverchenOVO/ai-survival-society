## Issues found and corrected

1. **Final exposure could remove both last agents in one tick.** The simulator now checks for a single survivor immediately after each environmental death, with a regression test.
2. **Food crisis initially reduced all supply generation.** It now suppresses only food spawns by 70%; rare resources preserve their normal spawn chance.
3. **Death was treated like alliance betrayal.** Ending an alliance due to death now preserves historical trust rather than inventing hostility.
4. **Cold local model load exceeded the initial timeout.** The tested cold request took about 20 seconds, so the default timeout is 30 seconds; the game still never waits for inference.
5. **The first ASAR desktop distribution failed startup/integrity checks.** The desktop build now uses unpacked application resources and was actually launched; a development instance must be closed before single-instance packaged tests.
6. **Initial scene readability.** Adjusted camera composition, contrast, typography, sky/ocean and terrain triangulation; retained the same dark observatory design and required controls.
7. **Initial Electron version had dependency advisories.** Updated to the available patched runtime; full npm audit reports zero vulnerabilities.

## Practical limits of this validation

The browser checks use installed Chrome because the Browser plugin and its skill were unavailable. Other browsers, macOS/Linux desktop builds and public deployment were not tested. Long-running behavior was exercised by repeated full matches and an accelerated continuous-mode test, not a literal five-hour wall-clock soak. Replay displays sampled positions/health plus final inspector state; it is not deterministic frame replay. Docker instructions are provided but Docker build was not tested on this machine.
