# AI Survival Society v1.7.0

## 空間智慧與實體互動

角色現在必須找到可走的路，通過門口，抵達設備的有效互動位置，才能使用這個世界。牆壁、關閉的門、深水、家具與其他角色會實際限制行動。

- **可靠路線**：authoritative 2.5D 碰撞、穩定 A*、地表成本、坡度限制、動態門與災害障礙、路徑快取與重新規劃。
- **狹路與人群**：角色保持實體間距，狹門有短預約與退讓；受阻時重新決策，不以 teleport 解決正常遊戲卡住。
- **設備容量**：26 個互動槽位保存預約與佔用。單床／醫療站／箱子／radio 不能同時被多人佔用；generator 提供兩個維修位置。
- **真正上下樓**：Watchtower 與 Ruins 上層使用顯式三維路線，角色沿樓梯往返。
- **共同幾何**：視線、互動與攻擊使用同一套 authoritative collision，不能隔牆治療或命中。
- **觀察工具**：設定中的空間除錯可顯示碰撞體、區域、路徑、入口、互動槽位及角色半徑；預設關閉。
- **延續歷史**：保存／恢復完整空間狀態；舊 checkpoint 明確遷移，已完成的舊 Story 與重播保留歷史座標。繁體中文預設與 English 切換保留。

## 使用方式

Windows 下載下方 `AI-Survival-Society-1.7.0.exe`，直接執行。原始碼環境可用根目錄 `Start-Society.ps1` 啟動本機網站。設定可調整語言、速度、連續模式與除錯圖層。

完整架構、效能、驗收結果與限制見 [V1.7_REPORT](https://github.com/oliverchenOVO/ai-survival-society/blob/main/docs/V1.7_REPORT.md)，實際舊版／新版診所路線對照見 [V1.7_COMPARISON](https://github.com/oliverchenOVO/ai-survival-society/blob/main/docs/V1.7_COMPARISON.md)。

## 已知限制

本版採 2.5D 圓形角色與簡化矩形／圓形碰撞體，並非完整 rigid-body physics 或 ORCA。重播延續五秒取樣，不是逐幀物理重演。正常模擬仍可能改目標、短暫受阻或全滅；不安排固定劇本來保證特定事件。Optional／stretch 功能的取捨已記錄於版本報告。
